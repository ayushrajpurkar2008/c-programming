# C Programming Learning Repository

A collection of C programs and mini-projects created while learning and practicing C programming.

## Repository Structure

* **[ATM Simulator](./mini-projects/atm-simulator/)** — A console-based ATM simulation for practicing balance checks, deposits, and withdrawals.
* **[Worktime Assistant](./mini-projects/digital-time-validator/)** — A time-based program for validating input, classifying time, checking work status, and calculating remaining work time.

## Concepts Practiced

* Variables and data types
* User input and output
* Conditional statements
* `switch-case`
* Logical and relational operators
* Input validation
* Basic arithmetic and program logic

## Getting Started

### Prerequisites

A C compiler such as **GCC** or **Clang** is required.

### Basic Compilation

Navigate to the directory containing the C source file and run:

```bash
gcc program_name.c -o program_name
./program_name
```

On Windows:

```bash
gcc program_name.c -o program_name.exe
program_name.exe
```
