# ATM Simulator

A beginner-level ATM simulator written in C to practice basic programming concepts.

## Features

* Check balance
* Deposit money
* Withdraw money
* Exit the program

## Concepts Practiced

* Variables
* `if/else`
* `switch`
* User input with `scanf`
* Basic program logic

## How to Run

Compile and run the program using a C compiler:

```bash
gcc atm-simulator.c -o atm
./atm
```
