# ATM Simulator

A beginner-level ATM simulator written in **C** as part of my C programming practice.

## Features

* Check account balance
* Deposit money
* Withdraw money
* Exit the program
* Basic transaction validation

## Concepts Practiced

* Variables and data types
* `if-else` statements
* `switch-case`
* User input using `scanf()`
* Arithmetic operations
* Basic program flow and logic

## How to Run

Make sure you have a C compiler such as GCC installed.

Compile the program:

```bash
gcc atm-simulator.c -o atm
```

Run it:

```bash
./atm
```

On Windows:

```bash
atm.exe
```

## Example

The program provides a menu where the user can choose an operation such as:

```text
1. Check Balance
2. Deposit
3. Withdraw
4. Exit
```

The selected operation is then performed based on the user's input.
